# Формат банка заданий

Как подготовить банк вопросов для загрузки: по этой странице файл собирается,
не заглядывая в код. Загружает файл **администратор**:
экран «Импорт» → домен «Экзамены» → вкладка «Банк заданий»; перед записью
идёт пробный прогон с предпросмотром и построчными ошибками. Ведёт банк
(правит и удаляет задания руками) академический директор на экране
«Пробные» → «Банк заданий».

Механика центра подготовки готова и работает: как только банк загружен,
экраны, прогресс по темам, статистика и слабые темы наполняются сами.

## Файл заданий

Таблица (CSV, разделитель — запятая, точка с запятой или табуляция;
первая строка — заголовки колонок). Одна строка — одно задание.

### Обязательные колонки

| Колонка | Что это | Пример |
|---|---|---|
| `exam_type` | Экзамен: `IELTS`, `TOEFL`, `SAT`, `ACT`, `Duolingo`, `HSK`. Другого значения импорт не принимает: строка отклоняется с причиной «неизвестный экзамен «…»», остальные строки файла загружаются | `IELTS` |
| `section` | Секция: `listening`, `reading`, `writing`, `speaking`, `math`, `verbal`, `english`, `science` | `reading` |
| `topic` | Тема (по ней считается прогресс и слабые темы) | `Skimming` |
| `text` | Текст вопроса | `What is the main idea of paragraph 2?` |
| `correct` | Верный вариант(ы): буква `A`; для нескольких — `A,C`. У письменных и устных — пусто | `B` |

### Необязательные колонки

| Колонка | Что это | По умолчанию |
|---|---|---|
| `subtopic` | Подтема внутри темы | пусто |
| `difficulty` | Сложность: `easy`, `medium`, `hard` | `medium` |
| `question_type` | Тип: `single` (один верный), `multiple` (несколько), `short` (короткий ответ), `writing` (эссе), `speaking` (устно) | `single` |
| `A`, `B`, `C`, `D`, `E`, `F` | Варианты ответа. Для `single`/`multiple` нужно ≥2 | пусто |
| `explanation` | Разбор, показывается после ответа | пусто |
| `expected_seconds` | Ожидаемое время на решение, секунд | пусто |
| `source` | Источник задания | пусто |
| `source_year` | Год источника | пусто |
| `image_file` | Имя приложенного файла-картинки | пусто |

### Для письменных секций (`question_type = writing`)

| Колонка | Что это |
|---|---|
| `criteria` | Критерии оценивания |
| `sample_answer` | Образец ответа |

Варианты и `correct` у письменных заданий не нужны: их проверяет человек.

### Для чтения: один текст — несколько вопросов

Текст-источник задаётся один раз и связывается с группой вопросов общим
ключом. У всех вопросов к одному тексту — одинаковый `passage_key`:

| Колонка | Что это |
|---|---|
| `passage_key` | Ключ группы (любая строка), одинаковый у вопросов к одному тексту |
| `passage_kind` | `reading` (текст) или `listening` (аудио) |
| `passage_title` | Заголовок текста |
| `passage_text` | Сам текст или расшифровка аудио |

Текст берётся из первой строки с этим ключом; остальные строки с тем же
`passage_key` только ссылаются на него.

### Для аудирования (`passage_kind = listening`)

| Колонка | Что это |
|---|---|
| `audio_file` | Имя приложенного аудиофайла |
| `passage_text` | Расшифровка аудио (не обязательно) |

Отрезок времени задаётся при ручной правке; в файле его пока нет.

## Аудио и изображения

Файлы аудио и картинок **прикладываются отдельными файлами** к той же
загрузке (форма позволяет выбрать несколько). В таблице в `audio_file`
и `image_file` стоит **имя файла** — по нему файл и подбирается. Имена
должны совпадать точно.

Файлы хранятся вне корня веб-сервера и отдаются только после проверки
прав: аудио вопроса ученик слышит внутри тренировки, по прямой ссылке
без входа файл не открывается.

## Форма на экране: то же, что умеет файл

Задание заводится и руками — «Пробные» → «Банк заданий» → «Завести задание».
Состав формы зависит от секции и повторяет возможности файла:

| Секция | Что в форме | Правило сервера |
|---|---|---|
| **Listening** | сверху «Аудио»: заголовок, файл (mp3 или m4a, до 20 МБ), расшифровка по желанию; под ним вопросы с вариантами, «Добавить вопрос» | без аудио ни источник, ни задание **не сохраняются** |
| **Reading** | сверху «Пассаж»: заголовок и текст; под ним вопросы, «Добавить вопрос» | вопрос по чтению заводится только к пассажу; текст один, вопросов несколько |
| **Writing, Speaking** | без вариантов: текст задания, критерии оценки, лимит слов (Writing) или минут (Speaking), образец ответа по желанию | варианты у этих секций отклоняются; тип вопроса следует из секции |
| **Math, Verbal и остальное** | вопрос с вариантами A–D и верным; галочка «Вопросы к тексту (пассаж)» открывает тот же блок пассажа | вариантов не меньше двух, верный ровно один |

Задание с источником правится вместе с ним: форма открывает пассаж (или аудио)
и все его вопросы разом. «Скрыть пассаж и его вопросы» убирает источник из
тренировок вместе с вопросами; ответы учеников остаются.

**В тренировке** вопросы к одному источнику идут одной страницей: пассаж или
плеер сверху, под ним все его вопросы. Пассаж попадает в тренировку целиком,
даже если заказано меньше заданий. Расшифровку аудио ученик видит только
в разборе. Аудио отдаётся после входа и только из собственной тренировки ученика.

**Открытый ответ.** У Writing и Speaking ученик пишет ответ сам (у Speaking —
тезисы устного ответа; запись голоса не ведётся). Ответ сохраняется и ждёт
проверки: «Пробные» → «Открытые ответы». Академический директор ставит оценку по шкале экзамена
и пишет комментарий — их ученик видит в разборе тренировки вместе с критериями;
имени проверяющего не видит. В процент верных открытый ответ не входит —
он считается по заданиям, которые проверяет машина. В пробный экзамен открытые
задания не попадают: его балл считается автоматически. Проверка помощником
не подключена: помощник эссе задаёт ученику вопросы по его истории, а не
оценивает ответ, и без переделки сюда не переносится.

## Собранный тест (пробный экзамен)

Пробный экзамен собирается на экране «Пробные» → «Пробные экзамены»:
набор секций, число вопросов в каждой, порядок секций, ограничение
времени на секцию и на тест целиком. Вопросы в секцию берутся из банка
по экзамену и секции.

## Пример строк

```csv
exam_type,section,topic,subtopic,difficulty,question_type,text,A,B,C,D,correct,explanation,expected_seconds,passage_key,passage_kind,passage_title,passage_text
IELTS,reading,Skimming,Main idea,medium,single,"What is the main idea of paragraph 1?","Tourism grows","Climate changes","Cities expand","Trade falls",A,"Первое предложение задаёт тему.",60,P1,reading,City growth,"Over the last decade cities have..."
IELTS,reading,Detail,Specific facts,hard,single,"In which year did the change start?","2001","2005","2010","2015",C,"См. второй абзац.",45,P1,reading,,
IELTS,writing,Task 2,Opinion essay,hard,writing,"Some people think... Discuss both views.",,,,,,"",1200,,,,
IELTS,listening,Numbers,Prices,easy,single,"How much is the ticket?","10","12","15","20",B,,30,L1,listening,Booking call,"Agent: The ticket costs twelve pounds."
```

Первые две строки — группа вопросов к одному тексту (`passage_key=P1`).
Третья — письменное задание без вариантов. Четвёртая — аудирование
с приложенным файлом (в `audio_file` укажите имя файла и приложите его).
