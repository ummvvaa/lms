# Формат теста профориентации

Как подготовить тест для раздела «Профтест»: по этой странице файл собирается, не
заглядывая в код. Загружает файл **учитель профориентации** (тот, у кого есть журнал
предмета профориентации) или **администратор**: экран «Профтест» → «Загрузить тест».
Перед записью идёт проверка с отчётом по листу и строке; пока в файле есть ошибки,
кнопка «Загрузить» закрыта. Пустой шаблон скачивается в том же окне, готовый образец —
`guides/examples/karta_interesov.xlsx` («Карта интересов» А. Е. Голомштока, 144 утверждения,
24 шкалы).

Баллы по шкалам считает платформа по ключу из файла. Модель получает только шкалы
с баллом не ниже порога теста и пишет разбор; минусы и «затрудняюсь» в разбор не идут.

## Книга xlsx из пяти листов

Названия листов — ровно такие; регистр и лишние пробелы не важны. Первая строка
каждого листа (кроме «Тест») — заголовки колонок.

### Лист «Тест» — две колонки: что и значение

| Строка | Что это | Обязательно |
|---|---|---|
| `Название` | как тест называется ученику и учителю | да |
| `Инструкция` | что сказать ученику перед началом | нет |
| `Порог для разбора` | наименьший балл шкалы, который уходит модели; по умолчанию `1` | нет |

### Лист «Ответы» — варианты ответа и их баллы

| Колонка | Что это | Пример |
|---|---|---|
| `Подпись` | как вариант выглядит на кнопке | `++`, `+`, `0`, `−`, `−−` или `Да`, `Нет` |
| `Баллы` | целое число, которое вариант прибавляет к шкале вопроса | `2`, `1`, `0`, `-1`, `-2` |
| `Описание` | подсказка ученику, необязательно | `очень хотелось бы` |

Лист нужен, если хотя бы у одного вопроса нет своих вариантов. Вариантов — от двух
до двенадцати, подписи не повторяются.

### Лист «Шкалы» — сферы интересов, типы, склонности

| Колонка | Что это | Пример |
|---|---|---|
| `Код` | короткий ключ, им вопросы ссылаются на шкалу; без пробелов, уникален | `bio` |
| `Название` | как шкала показывается в результатах | `Биология` |
| `Описание` | необязательно | |

Шкал — от одной до шестидесяти.

### Лист «Вопросы» — утверждения с ключом

| Колонка | Что это | Пример |
|---|---|---|
| `Номер` | целое от 1, уникально; ученик видит вопросы по номерам | `1` |
| `Текст` | утверждение или вопрос | `Проводить физические эксперименты` |
| `Шкала` | код шкалы с листа «Шкалы» | `phys` |
| `Знак` | `+` (по умолчанию) или `−`: у обратного пункта балл ответа идёт в шкалу с минусом | `+` |

**Вопрос со своими вариантами** (Климов, Холланд: «а» и «б» ведут в разные шкалы) —
вместо `Шкала` заполняются пары колонок `Вариант 1`, `Шкала 1`, `Баллы 1`,
`Вариант 2`, `Шкала 2`, `Баллы 2` и так далее. `Баллы N` пусто — считается `1`.
У такого вопроса кнопки — его варианты, а не варианты с листа «Ответы».

Вопросов — до пятисот.

### Лист «Интерпретация» — подписи к баллам

| Колонка | Что это | Пример |
|---|---|---|
| `Шкала` | код шкалы; пусто или `*` — для всех шкал | |
| `От`, `До` | границы диапазона включительно | `-12`, `-6` |
| `Подпись` | что показать рядом с баллом | `активно отрицается` |

Диапазон самой шкалы важнее общего. Листа может не быть — тогда у баллов нет подписей.

## Как считается балл

Балл шкалы — сумма баллов ответов по её вопросам с учётом знака; у вопроса со своими
вариантами балл и шкалу даёт выбранный вариант. Границы возможного балла (для полосок
в результатах) платформа считает сама из вариантов и ключа.

## Что происходит после загрузки

1. Тест появляется в списке выключенным. «Кому» — выбрать группы из своих составов
   профориентации, целиком или отмеченных учеников; администратор — любые группы.
2. Включённый тест ученик видит в разделе «Профтест», проходит, ответы сохраняются
   на сервере по ходу. Сдать можно только с ответами на все вопросы.
3. Одна сданная попытка на тест; «Разрешить пройти заново» у учителя уводит прежнюю
   попытку в историю.
4. «Разобрать» по группе: выбираются тесты из сданных, разбор получает каждый ученик,
   сдавший все выбранные. Тот же набор попыток второй раз у модели не запрашивается,
   пока не нажато «Пересчитать». Текст разбора учитель правит; ученику разбор показывается
   только после «Показать ученику».
5. Тест с попытками не удаляется, а уходит в архив; без попыток — удаляется вместе с файлом.
