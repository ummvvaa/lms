# Поля учеников списком: как загрузить

Инструкция для администратора, который загружает значения полей профилей
файлом: один файл — один домен, одна строка — один ученик. Таблица
поступления (ФИО, пароли, попытки IELTS и SAT, ссылки на документы)
загружается мастером импорта — о ней `ADMISSION_IMPORT.md`.

## Куда идти

«Импорт» → вкладка «Поля по CSV» → выбрать домен → «Данные учеников».
Вкладка открыта администратору; директора и кураторы вносят эти поля руками
в карточке ученика.

Шаги: файл → сопоставление колонок → предпросмотр → «Применить». До
«Применить» в базу не пишется ничего. Загрузку целиком можно отменить
в истории загрузок ниже на том же экране.

## Что должно быть в файле

Файл `.csv` (через запятую, в кодировке UTF-8) или книга Excel `.xlsx` —
читается первый лист. Первая строка — заголовки колонок.

**Одна колонка — ключ ученика**: почта или логин учётной записи, точное
совпадение. У 8–10 классов почты нет, их строку находит логин. Колонку
с ключом система узнаёт по заголовку («почта», «email», «логин», «ученик»);
если не узнала — выберите у неё «Ученик (почта или логин)».

Остальные колонки — поля выбранного домена. Колонку чужого домена система
не примет: её нужно загрузить отдельным файлом за свой домен. Поступление,
экзамены и документы ведутся только у 11 параллели — строка ученика 8–10
в таком файле будет названа и пропущена.

## Какие колонки система узнаёт

Колонка узнаётся по названию поля на любом из трёх языков интерфейса или
по одному из написаний ниже — заголовок должен совпасть с написанием целиком.
Не узнанную колонку можно назначить полю руками на шаге сопоставления.

## Как читаются значения

Значение проверяется так же, как при вводе в карточке ученика:

- **вариант из списка** (статус, уровень, трек) — ключом или подписью на
  любом языке интерфейса; другое значение отклоняется с перечнем вариантов;
- **да или нет** — «да», «нет», «иә», «жоқ», «yes», «no», 1, 0;
- **справочник** (вид спорта) — названием записи справочника;
- **число** — в границах поля: IELTS от 0 до 9, SAT от 400 до 1600,
  посещаемость от 0 до 100 %; дробная часть — через точку (`7.5`, не `7,5`);
- **дата** — только `ГГГГ-ММ-ДД` (`2026-11-05`).

Пустая ячейка ничего не стирает. Строка с ошибкой в значении не применяется
и называется в предпросмотре — остальные строки файла загружаются.

Посещаемость и число замечаний пересчитываются из журнала посещаемости
и замечаний: значение из файла держится, пока у ученика нет таких записей.

## Что видно после загрузки

Каждое изменённое поле — в журнале изменений с источником «импорт»
и пометкой, за какой домен загружал администратор. Внутренние статусы
и комментарии ученику не показываются, как и при вводе руками.
