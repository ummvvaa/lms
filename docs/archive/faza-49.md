# ЧАСТЬ 1. Каркас

## 1.1. Сайдбар — светлый

Тёмное меню из фазы 32 отменяется: оно спорило с содержимым и выглядело
чужим блоком. По макету:

- Белый фон, тонкая линия справа
- Логотип-герб и «BHS» сверху, кнопка сворачивания справа от них
- **Иконка каждого пункта в плитке** — квадрат со скруглением и мягкой
  серой заливкой. У активного пункта плитка залита оранжевым, иконка
  белая, текст и фон пункта — оранжевые мягкие
- Группы с подписями капителью: у ученика — Основное, Поступление,
  Работа; у директоров — по их разделам
- У пункта с вложенностью стрелка справа; у пункта с непрочитанным —
  оранжевая точка
- **Блок пользователя внизу закреплён:** аватар, имя с обрезкой, роль,
  стрелка вверх. Рядом кнопка-колокольчик со счётчиком

**Сайдбар не прокручивается вместе с содержимым.** Он стоит на месте,
прокручивается только правая часть. Если пунктов больше, чем влезает —
прокручивается список внутри сайдбара, а не вся страница.

Это касается всех семи ролей.

## 1.2. Шапка

Только поиск слева с подсказкой клавиши и кнопка «Как начать» справа.
Имя и колокольчик из шапки убраны — они внизу сайдбара. Название экрана
и описание — в самом содержимом, первой строкой.

## 1.3. Карусель на главной ученика

**Что это.** Не украшение, а список незакрытых мест: портфолио не
заполнено, до цели по экзамену не хватает, стипендии с дедлайном не
просмотрены, план не открыт неделю. Каждый сюжет — приглашение закрыть
одно место.

**Как собирается.** Сюжеты вычисляются на сервере по состоянию ученика.
Правила — справочник: условие, заголовок, описание, кнопка, цвет.
Не в коде.

**Устройство по макету:** карточка на цветном фоне высотой как
календарь рядом, слева надпись, заголовок в две строки, описание,
белая кнопка; справа геометрия; точки в правом верхнем углу, стрелки
по бокам; листается сама раз в несколько секунд, останавливается
при наведении.

**Когда исчезает — решение владельца:** когда незакрытых мест нет.
Тогда карусель убирается совсем, и **календарь занимает всю ширину.**
Появилось новое незакрытое место — карусель вернулась.

## 1.4. Календарь

По образцу: карточка на индиго, слева месяц со стрелками и сетка дней,
сегодняшний в белом кружке, дни с событиями с оранжевой точкой; справа
внутри той же карточки белая панель «Ближайшие события» — дата, название,
стрелка.

**Два размера, решение владельца.** Рядом с каруселью — компактный:
шрифт на ступень меньше, кружки дней меньше, панель событий уже.
Без карусели — на всю ширину, шрифт и кружки нормальные, панель
событий шире. Переключение автоматическое, вместе с каруселью.

Ученик видит свои события; директор — события своих учеников.

# ЧАСТЬ 2. Экраны ученика

## 2.1. Главная

Верх: карусель и календарь в ряд, или календарь один.

Ниже два на два: **Подготовка** (экзамен, решено, уровень с полосой,
серия и семь кружков недели, кнопка) и **Мои эссе** (плюс в заголовке,
строки с чипом статуса); **Задания на сегодня** (чекбоксы, срок, XP —
отметка прямо здесь) и **Готовность к подаче** (процент крупно, полосы
по пяти доменам, «данных пока нет» у пустых).

Задания на сегодня и разбивка готовности были потеряны в фазе 48
и возвращены с тестом — не потеряй снова.

## 2.2. Портфолио — две колонки

Сейчас в одну колонку с пустой правой половиной. По макету — **две
колонки**: слева шире — данные, справа уже — заполненность и профиль.

**Слева:** академические результаты плитками (подпись капителью, число
крупно, пояснение), цели по экзаменам строками с полями нормальной
ширины, готовность документов чек-листом с кнопками загрузки прямо
в строке.

**Справа:** заполненность с полосой и списком «что заполнить»,
профиль поступления парами подпись–значение, вузы в списке с процентами.

**Иерархия текста — главный дефект прошлой фазы.** Сейчас всё жирное
и одного размера, «Computer Science» наезжает на «Готовы платить».
По макету: подпись — мелкая капитель серым; значение — обычный вес
14–15px; крупными и жирными — **только числа в плитках**. Длинное
значение переносится и занимает всю ширину карточки.

**Внесение баллов и целей — в карточке, без перехода.** Сейчас кнопка
ведёт на другую страницу или не делает ничего. По макету: кнопка
«Внести баллы» раскрывает форму прямо в карточке, сохранение
отправляет предложение директору, значение появляется с пометкой
«ждёт проверки». Никаких переходов и возвратов.

## 2.3. Эссе — редактор во всю ширину

Сейчас редактор узкой колонкой слева, правая половина пустая.
По макету: **две колонки** — редактор две трети, помощник треть.

**Шапка:** название эссе, строка «черновик · N из M слов ·
автосохранение», справа чип статуса, кнопки сохранить версию и
отправить куратору.

**Редактор:** чипы-вкладки Текст / Версии / Замечания куратора, счётчик
слов справа, поле на всю ширину, под ним «Сохранено N минут назад».

**Помощник справа** пузырями: его вопросы на белом, ответы ученика
на мягком оранжевом, поле ввода внизу. Текст эссе не пишет.

**Ошибки при создании эссе.** Владелец получил HTTP 400 при выборе типа.
Найди причину, почини, проверь создание эссе каждого из девяти типов.

## 2.4. Мой путь

**После пяти шагов раздел исчезает из меню — решение владельца.**
Не остаётся серым внизу, не показывается свёрнутым — его нет. Вернуть
можно из профиля: «Показать шаги пути».

Пока шаги не пройдены — прежняя лестница.

**Шаги не должны выкидывать на другую страницу с возвратом.** Сейчас
«Заполнить профиль» уводит на экран, откуда надо вернуться, чтобы
нажать следующий шаг. По макету: у каждого шага рядом со статусом
кнопка «Открыть»; после выполнения шага на его экране появляется
полоса «Шаг выполнен — следующий: внести баллы» с кнопкой перехода
к следующему. Лестница не нужна как обязательная точка возврата.

# ЧАСТЬ 3. Шесть кабинетов руководителей

**Принцип для всех пяти директоров — решение владельца:** данные вносит
ученик, директор подтверждает. Таблицы у директоров становятся **только
на чтение** с подписью «значения меняет ученик, вы подтверждаете
в очереди». Ручной ввод и вставка текста остаются, но уходят из главного
экрана во второстепенные кнопки.

**Общий элемент — очередь «Ждут вашего решения»:** карточка с янтарной
полосой сверху, счётчик, строки — чекбокс, аватар, кто и класс, что
внёс, было → стало чипами, чип характера (новое / правка / расхождение
с величиной), кнопки подтвердить и отклонить. Внизу «Подтвердить
отмеченные». Отклонение просит причину, ученик её видит.

Дальше — что у каждого своё. Экраны в макете **разные**, не один
с подменой данных.

## 3.1. Кымбат — экзамены

Сверху четыре числа: средний IELTS с целью школы, средний SAT, мок
просел, ждут решения. Слева очередь баллов и целей. Справа «Мок просел»
с разницей винным чипом и «Ближайшие экзамены» с числом сдающих.
Внизу распределение школы по диапазонам IELTS полосами и «Без целей»
по классам.

Действия в шапке: банк заданий, пробные, внести результаты.

## 3.2. Асем — поступление

**Первым — то, что горит:** крупная оранжевая карточка «Дедлайны на этой
неделе»: сколько учеников подают, у скольких заявка не готова, первый
дедлайн. Кнопка к списку.

Четыре числа: среднее соответствие, без вузов, без плана, ждут решения.
Слева очередь целей, стран, специальностей и вузов в списках; ниже
баланс списков — только reach без safety, один вуз, сбалансирован.
Справа справочник: требования не подтверждены, дедлайн не проверялся
месяц — то, что ведёт она сама. И карточка про формулы A/B/C, которые
школа не задала, с кнопкой «Задать формулы».

## 3.3. Салтанат — школа

**Первым — «Кому позвонить сегодня»:** строки с учеником, причиной
одной фразой (три пропуска, просел по двум мокам, не заходил 24 дня,
пропустил дедлайн), чипом срочности и кнопкой с телефоном родителя
прямо в строке. Список собирается из пропусков, моков, активности
и дедлайнов — правила в справочнике.

Справа три числа: нужен контроль, без контактов родителей, не заходили
месяц.

Ниже: группы плитками — код, число учеников, число в риске цветом;
очередь контактов родителей; разговоры за неделю.

Посещаемость и замечания она по-прежнему вносит сама: этого ученик про
себя не рассказывает.

## 3.4. Арман — таланты

Четыре числа: в олимпиадной группе, материалов на проверке, в библиотеке,
портфолио пустое.

**Первым — материалы на проверке:** строки с типом источника, автором,
файлами, кнопки открыть / одобрить / отклонить. Чужой материал без
подтверждённых прав — чип «Проверить права».

Справа ближайшие олимпиады с числом участников. Ниже очередь достижений
и олимпиад от учеников; олимпиадная группа по предметам полосами.

## 3.5. Нурлыбек — спорт

**Первым — календарь стартов** той же карточкой, что у ученика: сетка
дней с точками, справа список — соревнование, дата, число учеников,
**«заявка не подана» янтарным**, если так.

Справа три числа. Ниже очередь выступлений, разрядов и видов спорта;
распределение по видам спорта полосами.

## 3.6. Администратор

Очереди подтверждений нет — ему нечего подтверждать.

Четыре числа: учеников и групп, не входили ни разу, расходы ИИ с лимитом,
блокировок входа.

Слева реестр школы: ученик, класс, группа, почта, статус входа. Фильтр
«Не входили».

Справа **«Требует ваших действий»** с кнопками прямо в строках:
приглашение не отправлено — выслать; пароль истёк — выпустить; адрес
заблокирован — снять. Ниже последние загрузки с пометкой «за домен».

# ЧАСТЬ 4. Дефекты

## 4.1. Эссе отдаёт 400 при создании

См. 2.3. Причину — в отчёт.

## 4.2. Портфолио: тексты наезжают

См. 2.2. Проверить снимком, что ни одно значение не перекрывает соседнее

## 4.3. Кнопки внесения ничего не делают

См. 2.2. Проверить каждую кнопку «Внести» в портфолио: форма

## 4.4. Правая половина пустая

Пройди все экраны ученика и всех директоров. На ширине ноутбука ни один
не должен оставлять правую треть пустой. Где содержимого мало — две
колонки с вспомогательной справа, как в макете.

## Критерии приёмки

Сайдбар светлый с плитками иконок, закреплён, не прокручивается
с содержимым, блок пользователя внизу — у всех семи ролей.

На главной ученика карусель собирается из незакрытых мест и исчезает,
когда их нет; календарь занимает освободившееся место и увеличивает
шрифт. Проверено на двух учениках прогона: у одного места есть, у другого
нет.

Портфолио в две колонки, иерархия текста по макету, ни одно значение
не наезжает, кнопки внесения открывают форму на месте.

Эссе создаётся всех девяти типов, редактор с помощником во всю ширину.

«Мой путь» исчезает из меню после пяти шагов, возвращается из профиля;
шаги не требуют возврата на лестницу.

Шесть кабинетов руководителей устроены по макету и отличаются друг
от друга. Таблицы директоров только на чтение. Очередь подтверждений
работает у пяти, у администратора — «Требует ваших действий» с рабочими
кнопками.

Снимки всех экранов всех ролей на двух ширинах в обеих темах
просмотрены: правая половина нигде не пустая, текст нигде не наезжает.

`pytest`, `api_probe`, линтеры, сборка — чисто.

и что осталось. Правила карусели — какие сюжеты заведены и по каким
условиям.
