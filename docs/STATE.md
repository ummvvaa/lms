## Что появилось в фазе 9
- Вход по почте и паролю; сессия по-прежнему в httpOnly cookie
- Microsoft убран целиком: ни MSAL, ни `accounts/entra.py`, ни `ENTRA_*` в настройках.
  Модель `Identity` осталась — провайдер стал `password`, внешний вход можно вернуть
  позже, не переделывая аутентификацию
- Требования к паролю: не короче 10 символов, не из списка распространённых,
  не совпадает с почтой. Смена при первом входе обязательна и проверяется на сервере
- Блокировка перебора: пять неудач подряд на учётную запись, пятнадцать на адрес,
  дальше нарастающая задержка от минуты до часа. Попытки — в журнале `LoginAttempt`
- Сброс пароля по ссылке на час, одноразовой; ссылка на вход выпускника осталась
- Экран «Пользователи» для роли `admin`: список, поиск, заведение, смена роли,
  отключение, массовое приглашение. Удаления нет — на людях висит аудит
- У Салтанат одна роль: флаг «видит всю школу» открывает чтение всех доменов
  и сводный вид, писать она по-прежнему может только в свой домен
- `manage.py create_dev_users` вместо файла с паролями; `docs/TEST_ACCOUNTS.md` удалён
  и закрыт `.gitignore`. В истории git он никогда не был — проверено
