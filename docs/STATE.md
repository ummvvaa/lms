## Фаза 44 — стипендии (VENTORME раздел 4)
- **Справочник** (`universities.Scholarship`) — организатор, страна, уровень,
  тип финансирования, сумма с валютой, три основания отдельными колонками
  (иностранцам / за заслуги / по нужде), дедлайн, ссылка, требования, вуз;
  плашка «не подтверждено» как у требований (инвариант №14). Ведёт директор
  по поступлению на `/scholarship-directory`, поля — в реестре у `admission`
- **Каталог ученика** (`/scholarships`): три числа сверху (в каталоге,
  с ближайшим дедлайном, сумма **по каждой валюте отдельно**), фильтры
  по стране, уровню, типу и основанию, карточка с сердечком. Срок — словами
  с сервера: «дедлайн сегодня», «остался 1 день», «через N дней»
- **Сохранённые** — вкладка со счётчиком, механизм избранного из фазы 40.
  Дедлайн уходит в календарь, за `REMIND_SCHOLARSHIP_DAYS` приходят
  уведомление и задача; её срок берётся из стипендии (инвариант №4)
- **Подбор под меня** — отбирают правила (страна и уровень из портфолио,
  срок не прошёл), модель формулирует по номерам из списка (инвариант №10);
  без модели — те же причины словами, пустой справочник говорит прямо
- **Файлом** — у администратора: «Импорт» → «Поступление» → «Стипендии»,
  колонки, пробный прогон, применение; записи приходят неподтверждёнными,
  директору 403 и подсказка. Ему же — вкладка «Кто что сохранил»: дедлайн
  на неделе, кто сколько сохранил, кто не сохранил ни одной
