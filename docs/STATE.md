## Сейчас работает
- Каталог выпускников с фильтрами; профиль на момент поступления — неизменяемый срез
- Менторство только через сотрудника: до одобрения выпускник запроса не видит вовсе
- Архив эссе выпускников — исключительно с явного согласия, с указанием вуза
- Переход ученик → выпускник: предложение привязать личную почту за 2 месяца, автоперевод по дате
- Фоновая сверка дедлайнов по белому списку (домены вузов + Common App); факт несёт ссылку и цитату
- Расхождение уходит в Suggestion директору по поступлению — база сама не меняется
- Дайджест по домену открывается при входе; healthz и readyz отвечают
- Боевой контур: gunicorn, nginx с TLS, отдельные worker и beat, ротация логов, Sentry
- Бэкапы по расписанию с автопроверкой восстановления; проверено развёртывание на чистой машине
- 167 тестов pytest зелёные; ruff, black, eslint, prettier чистые; OpenAPI-схема без ошибок
