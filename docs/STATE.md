## Фаза 43 — конструктор эссе (VENTORME раздел 6)
- **Типы документов** (`roadmap.EssayDocType`) — справочник из девяти
  посеянных типов (Personal Statement … без типа) с описанием и лимитом
  слов; ведёт директор по поступлению на `/essay-content`. Ученик выбирает
  тип плиткой, поиск по типу, «требования вашим университетам» из списка вузов
- **Гайд** (`EssayGuide`) — четыре шага (что это, вопросы, ошибки, советы),
  справочник по типу; показывается перед первым эссе типа (localStorage),
  пропускается и вызывается повторно. **Быстрая проверка** (`EssayCheckQuestion`)
  — три вопроса, выбор подсвечивается верным с объяснением; это закрепление,
  результат никуда не идёт
- **Редактор** (`Essays.tsx`): автосохранение версией, счётчик слов с лимитом
  типа, статусы и отправка куратору. Сбоку — **чат с помощником**: он задаёт
  вопросы (механика фаз 4–5, `essay_assist`), **текст эссе не пишет** —
  кнопок «улучшить»/«переписать» нет вовсе; переписка (`EssayAssistLog`)
  видна ученику и куратору (`/essays/:id/assist-log/`)
- **Чтение дня** (`EssayExample`) — пример сверху раздела, меняется ежедневно
  (по дню года), из архива примеров директора по поступлению
- Ученик теперь **сам заводит и ведёт своё эссе** (`OwnEssayOrStaff`):
  выбирает тип, лимит, пишет версии; задачи директора он по-прежнему не правит
