# Состояние проекта
Обновлено: 2026-08-21   Последняя фаза: 5 — Движок предложений и ИИ

## Готово
- Фаза 1: монорепо, Docker Compose, полная схема БД, админка, импорт, pytest
- Фаза 2: вход через Entra и ссылки, роли из групп, права по доменам, каркас фронта
- Фаза 3: батч-сохранение, табличный режим, карточка ученика, шесть дашбордов, Readiness
- Фаза 4: справочник требований, движок соответствия, роадмап, эссе
- Фаза 5: предложения, сопоставление имён, Celery, инструменты модели, ограничения ИИ

## Сейчас работает
- Вставка переписки → фоновый разбор → предпросмотр; ничего не пишется без человека
- Применение одной транзакцией со сверкой прежнего значения; конфликт не затирает чужую правку
- Откат возвращает прежние значения и дополняет журнал, а не переписывает его
- Валидатор в коде: строка чужого домена не попадает даже в предложение
- Матчер имён: три алфавита, склонения, инициалы, однофамильцы; неоднозначность решает человек
- Celery: разбор и вызовы модели в фоне, эндпойнт отдаёт id задачи, фронт опрашивает прогресс
- Инструменты модели типизированы и проверяются по роли; в модель уходят только нужные поля
- ИИ по эссе только задаёт вопросы; вся активность видна куратору в EssayAssistLog
- Без ключа LLM система работает: разбор правилами, объяснения из движка соответствия
- 153 теста pytest зелёные; ruff, black, eslint, prettier чистые; OpenAPI-схема без ошибок

- Разбор `parse_university` и `parse_certificate` пока не реализован — только кнопки в реестре
- Проверка подписи Entra на живом тенанте не гонялась: нет реальных ENTRA_* доступов
