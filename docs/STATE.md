## Главное, что нашёл аудит
- **Из браузера не проходит ни одна запись.** `CSRF_TRUSTED_ORIGINS` читается только в
  prod-настройках, поэтому в контуре разработки любой аутентифицированный POST/PATCH
  отбивается 403 — включая «Выйти». Интерфейс фаз 3–6 в браузере никогда не проверялся
- Таблица показывает первые 50 учеников из 87: `page_size` игнорируется, пагинации нет
- Нечисловое значение в числовой ячейке роняет батч в 500
- Из двенадцати «именованных действий» помощника работает одно
- Семь пунктов навигации директоров ведут на один и тот же дашборд

## Права по доменам держатся
Прогон API под шестью ролями чист: ученик не видит ярлыков и чужих карточек,
директор не пишет в чужой домен ни через профиль, ни через батч, конфликт по
`expected` отрабатывает. Это единственная часть, к которой у аудита нет вопросов.
