# Состояние проекта
Обновлено: 2026-08-21   Последняя фаза: 1 — Фундамент и модель данных

## Готово
- Фаза 1: монорепо, Docker Compose на 6 сервисов, полная схема БД, админка, импорт, pytest

## Сейчас работает
- `docker compose up` из корня поднимает postgres, redis, backend, celery, frontend, nginx; вход через http://localhost:8080
- Миграции (по одной на приложение) применяются на чистой БД; база стартует пустой
- Админка на /admin/: заводятся вузы, программы, раунды с дедлайнами, учебные группы, ученики с пятью профилями
- `manage.py import_students <csv|xlsx>` создаёт учеников и профили, идемпотентен по email, пишет AuditLog с источником `import`
- Реестр владения полями `backend/core/domains.py` — единственный источник для прав, валидатора и колонок фронта
- 23 теста pytest зелёные; ruff и black чистые

## Следующая фаза
- Фаза 2: вход через Microsoft Entra (MSAL на фронте, проверка JWKS на бэке), своя сессия в httpOnly cookie
- Роли из групп Entra, вторая дверь для выпускников по одноразовой ссылке
- DRF-permissions поверх реестра доменов, фильтрация ярлыков для роли `student` на бэкенде
- Каркас фронта: layout по ролям, роутинг, TanStack Query, типы из OpenAPI; дизайн-токены в CSS-переменные

## Долги и известные проблемы
