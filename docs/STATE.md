## Фаза 42 — центр подготовки (VENTORME раздел 7)
- **Формат банка расширен** (`prep.Question` + `QuestionPassage`): подтема,
  тип вопроса (single/multiple/short/writing/speaking), изображение,
  ожидаемое время, источник и год; для чтения — текст-источник, один на
  группу вопросов; для аудирования — аудиофайл, расшифровка, отрезок;
  для письменных — критерии и образец. Собранный тест: секции с временем
  на секцию и на тест. Аудио/картинки — в закрытом хранилище, отдаются
  своим маршрутом с проверкой прав. Семь экзаменов: добавлены Duolingo и HSK
- **`docs/QUESTION_BANK.md`** — полное описание колонок, обязательного,
  как класть аудио и связать текст с группой вопросов, примеры строк
- **Импорт** (`prep/imports.py`) принимает полный формат: `passage_key`
  связывает вопросы с текстом, `audio_file`/`image_file` подбирают
  приложенные файлы по имени; строка с ошибкой не роняет файл, есть `dry_run`
- **Экраны ученика** (`Prep.tsx`): семь плиток экзаменов с прогрессом →
  форматы (тренажёр / пробник / работа над ошибками / курс-заглушка) →
  секции с прогрессом → темы с полосой по каждой → фильтры → «Начать
  практику». Вкладки Подготовка · Статистика · Теория. Пустой банк
  объясняется на каждом экране
- **Статистика** (`prep/prep_center.py`): прогноз балла за тренировки
  («нужно N ответов», не результат экзамена), до цели, рост, серия,
  календарь активности, слабые темы, бейджи с замком на закрытых
- **Теория** (`prep.TheoryLesson`): уроки с уровнем и временем чтения,
  группировка по секциям; ведёт академический директор на «Пробных» →
  «Теория», файл урока в закрытом хранилище; ученик читает в центре
